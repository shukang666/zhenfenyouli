统计口径
1. 打卡、用户、订单、商品、店铺等均已剔除回收站（软删除）数据，与各列表页口径一致。
2. 打卡量按有效用户计算，用户已删除的打卡不计入。
3. 积分发放 = 积分账户正向变动，不含扣减。
4. 待发货订单含"待发货 + 待发货（退款被拒）"；退款售后含"退款申请 / 退货申请 / 待退货 / 退款中"，与订单列表状态分组一致。
性能说明
