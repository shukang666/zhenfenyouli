# 项目业务全景

这是一个面向社区居民的环保类微信小程序，配套一套 PC 后台管理系统。小程序前端用 uni-app 和 uView，后台和接口是 ThinkCMF（ThinkPHP）做的，数据库是 MySQL。产品以垃圾分类为日常主线，再铺开低碳活动、积分激励、志愿服务、健康管理、知识学习和社区论坛，做成一套能运营的社区环保工具，而不是单次宣传页。

小程序底部是自定义 tabbar，五个 Tab 分别是首页、活动、健康、积分权益、我的。首页会走骨架屏，减轻第一次进来的空白感。用户要先选小区、绑定小区，很多打卡和活动才按小区范围走。首页能看通知、入口、推荐内容和积分相关信息；热门活动里固定露出垃圾真分、我和七贤岭等社区专题入口，和 activity Tab 的专题网格相呼应。底部有使用教程，点下去是新手引导，带着认五个 Tab 和垃圾分类、我和七贤岭这些入口。

垃圾分类是最核心的日常。居民要先完成「学考一体」的学前关卡（学分类要点并答对练一练），才有拍照打卡拿积分的资格；这和七贤岭的「认识七贤岭」不是同一套表、同一套接口，改门禁时不要和七贤岭内容混在一起。打卡前先经过入口页引导：选投放场景（家庭、办公、沿街），再选垃圾种类（可回收、厨余、有害、其他），然后进拍照页并自动带上对应的上报类型。家庭等场景可在小程序里布置自家投放点位，四处都配置完整时系统会一次性发放布置激励积分。打卡要上传分类投放照片，系统会用感知哈希判断重复图，减少拿同一张图反复刷分。打卡成功记环保积分。后台可以精选、置顶、删打卡并留日志。我的打卡和精选打卡分别在独立列表页查看。小程序里还有一键打卡入口、排行榜，以及学习、考试相关的数据展示，方便居民知道自己学到哪、考过没有。

活动在活动 Tab 里，按公益行动、低碳生活、亲子、垃圾分类、七贤岭等主题来分，同时有一块「社区专题」网格：我和七贤岭、步行山海净美家园、七贤岭绿色二手集市、垃圾真分小课堂。前一项进地方主题枢纽页，后三项先进分会场列表，再选具体活动或地点名称进入，避免只显示抽象分类名。活动可以在小程序里直接报名参加，也可以做成扫码才能进的场次，后台给每场活动生成专属小程序码，避免互相覆盖。活动还有配置式详情和 Web 式（H5 web-view）两种展示。每场活动还能配打卡动作，比如限时拍照、填表、订阅通知。详情页主要展示能得多少积分、有多少人参加。活动列表支持置顶。公益行动等分类里仍可进垃圾分类学习和「我和七贤岭」快捷入口。

「我和七贤岭」是一条相对独立的地方主题线，叙事上是「认识 · 发现」两步：认识七贤岭用一条短视频带居民快速了解本地人文与地理，看完做三道固定小互动题，全对即完成认识并记进度、首次可发积分，对外不叫学考、也不再做六大板块长篇边读边测；发现步对接「100 个瞬间」等影像征集类 Web 式或配置式活动，以及往期活动风采回顾。活动 Tab 和首页会把「我的七贤岭 / 我和七贤岭」作为专题卡片主推。探索、记录、守护七贤岭下面挂的是对应主题活动，不要和垃圾分类打卡前的学考门禁混谈。

积分贯穿整端。居民通过垃圾分类打卡、参加活动、每日签到、分类知识挑战答题、认识七贤岭小互动、邀请等行为拿积分，到积分权益商城里兑商品或优惠券，支持购物车、下单、发货、退款。明细里能看每一笔积分或余额变动，也能按类型、时间筛。后台管签到规则、积分流水、充值和提现。另外还有会员等级和 VIP 套餐、优惠券（答题券、商家券）这些激励层。

志愿督导面向申请成为督导员的居民。用户在小程序提交申请，后台审核通过后给督导权限。督导可以做点位巡查打卡、记录巡查情况。居民或志愿者可以用随手拍上报问题，后台审核通过后会自动变成整改任务，也可以由后台手动发布任务。志愿者在小程序里领取整改任务、提交整改照片，后台审核通过再发积分。随手拍位置可以是小区点位，也可以是非小区商家地址。

健康 Tab 给居民提供预约、健康相关问卷或答题、资料阅读一类服务，和环保主线并列，方便社区把健康宣教放进同一套小程序。后台能看预约和问卷记录。

知识学习分几条，不要混。学会分类知识是文章列表和详情，给居民补分类常识，详情一般是分段长文。分类知识挑战是每天随机抽五道题、满分十分、每天限答一次，答对给积分。七贤岭侧产品入口已收敛为「认识七贤岭」视频加三道题，服务端用独立 intro 配置与模块过关记录；后台仍可能保留旧的七贤岭文章与题库数据，但不要再把「篇章学考融合、绑 knowledge_id 逐篇解锁」当成当前对用户的主路径。垃圾分类打卡前的学考一体是 Forum/Clock 相关门禁，表和页面都不要和七贤岭混改。

社区论坛给居民发图文帖、点赞、评论。后台除了管帖子，还有一套和论坛表相关的点位巡查、桶边督导处理记录，删帖可以扣分并写删除日志。不要把论坛发帖和巡查处理当成同一件事。

商家里可以入驻、上架商品、处理订单。居民端在积分权益和商城里完成浏览、下单。后台管商家审核、商品、订单和优惠券。

PC 后台是给运营和街道用的，不是小程序那套界面。运营看板上能看打卡、活动、积分这些汇总。菜单和权限按角色走。列表普遍能搜、导出、分页。面向用户的改动会记在更新记录里。外勤人员还有单独的工作 Pad 入口，用后台账密登录，但登录态和驾驶舱后台必须分开，进去是督导监测录入和统计，不要一退出又进管理系统后台。手机上另有 OA 办公入口，同样用管理员账密，登录态再单独一套，只给手机用，不和 Pad、驾驶舱、电脑后台串 session。

对其他 AI 来说，记住这是「一个仓库里的小程序前端、小程序接口、PC 服务端渲染后台」三套代码，业务上以社区垃圾分类打卡得积分为轴，活动专题与七贤岭认识发现、志愿整改、商城、健康、论坛都挂在这个社区运营体系上即可；改七贤岭认识页、活动 Tab 专题或打卡门禁时，先分清是垃圾分类链还是七贤岭链，再动代码。
