========================================
    PDF 转高清图像工具 - 使用说明
========================================

【功能说明】
-----------
将 PDF 文件逐页转换为高清无损图像
- 支持批量转换多个 PDF 文件
- 支持 DPI 调节（150-600 DPI）
- 支持额外缩放倍数（1x-4x）
- 支持 PNG/JPG/BMP/TIFF 多种格式
- 多页 PDF 自动按页拆分输出


【安装依赖】
-----------
pip install PyMuPDF


【使用方式】
-----------
方式一：直接运行 Python 脚本
    python pdf_to_image.py

方式二：打包成 exe 后双击运行
    pyinstaller pdf_to_image.spec
    生成目录：dist/PDF转高清图像工具.exe


【参数说明】
-----------
1. DPI（清晰度）：
   - 150 DPI：速度最快，适合预览
   - 300 DPI：高清推荐，日常使用
   - 600 DPI：极高清，适合印刷/存档

2. 额外缩放倍数：
   - 在 DPI 基础上进一步放大图像尺寸
   - 例如 DPI 300 + 2.0 倍 = 等效 600 DPI

3. 输出格式：
   - PNG：无损，支持透明背景（推荐）
   - JPG：有损压缩，文件较小
   - BMP：无压缩，文件最大
   - TIFF：印刷级质量


【输出规则】
-----------
- 单页 PDF：输出为 "文件名.png"
- 多页 PDF：输出为 "文件名_第1页.png"、"文件名_第2页.png"...
- 默认保存到 PDF 文件所在目录（也可自定义输出目录）


【注意事项】
-----------
- DPI 越高、缩放越大，输出文件越大，转换越慢
- 600 DPI + 4x 缩放可能产生数 GB 的图像文件
- 建议先用低参数测试，确认效果后再批量高清输出
